## 一、核心概念

1. **人民币单位**：人民币的单位有元、角、分，元最大，分最小。
2. **面值认识**：认识100元、50元、20元、10元、5元、1元、5角、1角、5分、2分、1分等面值。
3. **单位换算**：元与角、角与分之间的进率都是10。
4. **付钱方法**：买东西付钱可以用不同组合，学会按面值从大到小搭配。
5. **找钱**：付出的钱比商品价格多时，要计算应找回多少。
6. **够不够问题**：先算总价，再与带的钱比较，判断够不够。

## 二、公式与定理

| 名称 | 公式/内容 | 适用条件 |
| --- | --- | --- |
| 元角换算 | 1元=10角 | 元与角之间互换 |
| 角分换算 | 1角=10分 | 角与分之间互换 |
| 元分换算 | 1元=100分 | 元直接化成分 |
| 总价计算 | 总价=各件商品价格相加 | 一次买多件物品 |
| 找零计算 | 找回的钱=付出的钱-商品价格 | 付款多于标价时 |

## 三、解题方法

1. **摆学具模拟法**：用人民币学具摆一摆，实际操作付钱和找钱。
2. **列举付钱法**：按面值从大到小有序列举所有付钱组合，不重复不遗漏。
3. **统一单位法**：比较大小时先统一成角（或元），再比较计算。
4. **画线段图法**：把"带的钱、花的钱、剩的钱"画成线段图分析数量关系。

## 六、常见考点

1. 辨认各种面值的人民币并说出总钱数。
2. 元角分单位换算与大小比较。
3. 用不同方法付钱（问"可以怎样付钱"）。
4. 计算买几件商品的总价和应找回的钱。
5. 判断带的钱够不够买某商品，并说明理由。
6. 模拟购物情境中的补钱、换钱问题。
