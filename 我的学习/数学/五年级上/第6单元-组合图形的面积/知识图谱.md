## 一、核心概念

1. **组合图形**：由两个或两个以上的基本图形（长方形、正方形、三角形、平行四边形、梯形）组合而成的图形。
2. **分割法**：把组合图形分割成几个已学过的基本图形，分别求出面积再相加（求和思路）。
3. **添补法**：把组合图形添补成一个大的基本图形，用大图形面积减去添补部分的面积（求差思路）。
4. **方法选择原则**：分割或添补后基本图形的数量尽量少、所需数据已知或可求；同一图形常有多种解法，可互相检验。
5. **不规则图形面积的估计**：放在方格纸上，大于等于半格的算1格，小于半格的舍去，数出格数即近似面积；也可把不规则图形近似看作某个规则图形估算。
6. **公顷**：测量土地面积的单位，边长100米的正方形面积是1公顷，1公顷=10000平方米。
7. **平方千米**：测量较大土地面积的单位，边长1000米（1千米）的正方形面积是1平方千米，1平方千米=100公顷=1000000平方米。

## 二、公式与定理

| 名称 | 公式/内容 | 适用条件 |
| --- | --- | --- |
| 分割法求面积 | 组合图形面积 = 各部分基本图形面积之和 | 图形可拆成几个基本图形 |
| 添补法求面积 | 组合图形面积 = 补成的大图形面积 − 添补部分面积 | 图形接近完整大图形时 |
| 基本图形面积 | 长方形S=ab；正方形S=a²；平行四边形S=ah；三角形S=ah÷2；梯形S=(a+b)h÷2 | 分割/添补后使用 |
| 方格估算法 | 满格数 + 不满格按半格计（≥半格算1格，<半格舍去） | 估计不规则图形面积 |
| 公顷换算 | 1公顷 = 10000平方米 | 土地面积计算 |
| 平方千米换算 | 1平方千米 = 100公顷 = 1000000平方米 | 较大区域面积计算 |

## 三、解题方法

1. **分割求和法**：画辅助线把组合图形切成几个基本图形，标出每块的底和高，分别计算后相加。
2. **添补求差法**：把凹进去的部分补上，看成一个大长方形（或其他基本图形），再减去补上的部分。
3. **数据标注法**：解题前先把已知长度标在图上，根据图形特征推出隐含数据（如对边相等、剩余长度=总长−已知长）。
4. **方格纸估算法**：把不规则图形轮廓描在方格纸上，按"≥半格算1格"的规则数格子，得到面积的近似值。
5. **单位换算三步法**：判断大化小（乘进率）还是小化大（除以进率），记准进率10000（平方米↔公顷）、100（公顷↔平方千米）。

## 六、常见考点

1. 用分割法或添补法计算组合图形的面积（常考L形、T形、凹字形等）。
2. 根据图形特征求出隐含边长，再计算面积。
3. 一题多解：用两种不同方法计算同一组合图形并比较结果。
4. 用数方格的方法估计不规则图形（如树叶、池塘）的面积。
5. 公顷、平方千米的认识与单位换算，及在土地面积实际问题中的应用。
6. 计算组合图形面积的实际问题（如粉刷墙壁、铺草坪并计算费用）。
