## 一、核心概念

1. **分数的再认识**：把一个整体（单位"1"）平均分成若干份，表示这样一份或几份的数叫分数；同一个分数，对应的整体不同，表示的具体数量也不同。
2. **分数单位**：把单位"1"平均分成若干份，表示其中一份的数叫分数单位（如 3/5 的分数单位是 1/5，有3个这样的分数单位）。
3. **真分数与假分数**：分子比分母小的分数叫真分数（小于1）；分子大于或等于分母的分数叫假分数（大于或等于1）。
4. **带分数**：由整数部分和真分数部分组成的分数（如 1又1/4），是假分数的另一种书写形式，大于1。
5. **分数与除法**：被除数÷除数 = 被除数/除数（除数≠0），即 a÷b = a/b（b≠0）；分数的分子相当于被除数，分母相当于除数。
6. **分数的基本性质**：分数的分子和分母同时乘或除以相同的数（0除外），分数的大小不变。
7. **约分**：把一个分数化成和它相等，但分子、分母都比较小的分数；分子、分母只有公因数1的分数叫最简分数，约分时通常要约成最简分数。
8. **通分**：把分母不相同的分数分别化成和原来分数相等、并且分母相同的分数；一般用几个分母的最小公倍数作公分母。
9. **最大公因数与最小公倍数**：几个数公有的因数中最大的叫最大公因数；公有的倍数中最小的叫最小公倍数。

## 二、公式与定理

| 名称 | 公式/内容 | 适用条件 |
| --- | --- | --- |
| 分数与除法 | a÷b = a/b（b≠0） | 求一个数是另一个数的几分之几 |
| 分数的基本性质 | a/b = (a×m)/(b×m) = (a÷m)/(b÷m)（m≠0） | 约分和通分的依据 |
| 假分数化带分数 | 分子÷分母：商作整数部分，余数作新分子，分母不变 | 假分数分子不是分母倍数时 |
| 带分数化假分数 | 分母不变，分子=整数×分母+原分子 | 带分数参与计算前 |
| 最大公因数 | 用列举法或短除法：公有质因数的乘积 | 约分、实际问题 |
| 最小公倍数 | 用列举法或短除法：公有质因数与各自独有质因数的乘积 | 通分、实际问题 |
| 分数大小比较 | 同分母比分子；同分子比分母（分母小的反而大）；异分母先通分 | 比较分数大小 |

## 三、解题方法

1. **列举法求最大公因数/最小公倍数**：分别列出各数的因数（或倍数），圈出公有的，找最大（最小）的一个。
2. **短除法求最大公因数/最小公倍数**：用公有质因数连续去除，最大公因数=左边除数的乘积，最小公倍数=除数与商全部相乘。
3. **约分化最简分数**：用分子分母的最大公因数一次约分，或用公因数逐次约分，直到分子分母互质（只有公因数1）。
4. **通分比较大小**：先求各分母的最小公倍数作公分母，利用分数基本性质改写各分数，再比较分子。
5. **求一个数是另一个数的几分之几**：用"比较量÷标准量（单位'1'的量）"，结果写成分数并约成最简。

## 六、常见考点

1. 用分数表示图中阴影部分，或根据分数画出整体（理解整体"1"不同结果不同）。
2. 判断真分数、假分数，假分数与带分数互化。
3. 分数与除法的关系：用分数表示除法的商；求一个数是另一个数的几分之几。
4. 利用分数基本性质填空（分子或分母变化后求另一个）。
5. 求两个数的最大公因数和最小公倍数，并解决实际问题（如铺地砖、分组、同时发车）。
6. 约分（化成最简分数）与通分，比较异分母分数的大小。
