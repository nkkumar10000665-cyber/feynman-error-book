## 一、核心概念

1. **克（g）**：计量较轻物体的质量单位，如1枚2分硬币约重1克。
2. **千克（kg）**：计量较重物体的质量单位，如2袋盐约重1千克。
3. **吨（t）**：计量很重或大宗物品的质量单位，如一头大象的质量用吨作单位。
4. **质量单位进率**：相邻单位之间进率是1000。
5. **单位选择**：根据物体轻重选择合适的质量单位。
6. **秤的认识**：台秤、天平、电子秤等称量工具及读数。

| 名称 | 公式/内容 | 适用条件 |

| 千克与克 | 1千克=1000克 | 质量单位换算 |
| 吨与千克 | 1吨=1000千克 | 质量单位换算 |
| 相邻进率 | 克→千克→吨，相邻进率都是1000 | 所有质量单位换算 |

## 三、解题方法

1. **单位换算"大化小乘进率"**：大单位化小单位乘1000，小单位化大单位除以1000。
2. **参照物比较法**：用1克、1千克、1吨的实际参照物估计物体质量。
3. **统一单位再计算**：不同单位的数量比较或加减前先统一单位。
4. **联系生活实际**：结合购物、载重等情境理解单位意义。
