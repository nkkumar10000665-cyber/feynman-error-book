## 一、核心概念

1. **五感词汇**：touch（触摸）、feel（感觉）、smell（闻）、taste（尝）、look（看）、see（看见）、hear（听）。
2. **触感形容词**：soft（软）、hard（硬）、smooth（光滑）、rough（粗糙）、thick（厚）、thin（薄）。
3. **气味味道形容词**：sweet（甜）、sour（酸）、nice（香）、bad（难闻）、fresh（新鲜）。
4. **感官问答句型**：How does it feel/smell/taste? — It's soft. / It smells nice. / It tastes sweet.（第三人称 does 用法）。
5. **观察描述句型**：What can you see? — I can see a rainbow. Look at the sky.（用 can see 描述所见）。
6. **现在进行时复现**：The sun is rising. The birds are singing.（描述正在变化的景象）。
7. **交际功能**：用五官感受描述事物特征、询问并回答物品触感与味道、描述眼前所见景象。

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 感官动词 + 形容词 | feel/smell/taste/look + 形容词（不加 ly） | 描述事物给人的感觉 |
| How does it …? | How does it feel/taste? — It is/tastes … | 询问第三人称事物感受 |
| 现在进行时 | be + V-ing：is rising / are singing | 描述眼前正在发生的事 |
| can see 句型 | What can you see? — I can see … | 描述能看到的东西 |

## 三、解题方法

1. **感官动词定形容词**：feel/smell/taste/look 后面选形容词，排除副词选项。
2. **三单 does 定位**：问句主语是 it/he/she，助动词用 does，动词还原原形。
3. **标志词判时态**：Look! / Listen! / Now! 一出现，立刻用现在进行时。
4. **分类记忆法**：把形容词按"摸（soft/hard）、闻（nice/bad）、尝（sweet/sour）"三类分开记。
