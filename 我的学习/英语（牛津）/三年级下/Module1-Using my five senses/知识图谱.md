## 一、核心概念
1. **颜色词汇**：red, yellow, blue, green, orange, purple, pink, black, white, brown（红/黄/蓝/绿/橙/紫/粉/黑/白/棕）
2. **问颜色**：—What colour is it? —It's red.（什么颜色？红色。）
3. **味道词汇**：sweet, sour, bitter, salty（甜/酸/苦/咸）；candy, lemon（糖果/柠檬）
4. **问味道**：—How does it taste? —It's sweet.（尝起来怎么样？甜的。）
5. **声音词汇**：car, bus, bike, plane, ship（车/公交/自行车/飞机/船的声音）
6. **问声音**：—What can you hear? —I can hear a car.（你能听到什么？）
7. **五感动词**：see（看）、hear（听）、taste（尝）、smell（闻）、touch（摸）
8. **交际功能**：谈论物品颜色、食物味道、听到的声音

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| What colour 问颜色 | What colour + be + 主语? → It's + 颜色. | 询问物品颜色 |
| 味道问句 | How does it taste? → It's + sweet/sour/bitter. | 询问食物味道 |
| 声音问句 | What can you hear? → I can hear + a/an + 名词. | 询问听到的声音 |
| can + 感官动词 | I can see/hear + 名词. | 表达能看到/听到的东西 |
| 名词复数 +s/es | 一般+s；s/x/ch/sh 结尾+es | 两个及以上物品 |

## 三、解题方法
1. **感官分类记忆法**：把动词按看/听/尝/闻/摸五类整理成表
2. **实物联想法**：lemon→sour，candy→sweet 实物配对记忆
3. **问答关键词法**：What colour 答颜色词；How does it taste 答味道词
4. **听音辨声法**：听力题先想交通工具单词表再听声音
5. **颜色混色小实验法**：red+yellow=orange 帮助记忆颜色词
