## 一、核心概念
1. **动物园动物**：lion, tiger, monkey, panda, elephant, zebra（狮子/老虎/猴子/熊猫/大象/斑马）
2. **动物复数**：I like pandas. 用复数表一类动物
3. **玩具词汇**：doll, kite, ball, robot, toy car, toy train（洋娃娃/风筝/球/机器人/玩具车/玩具火车）
4. **喜好表达**：I like + 名词（复数）. I don't like...（我喜欢/不喜欢……）
5. **食物饮料**：bread, rice, milk, juice, water, cake, egg, biscuit（面包/米饭/牛奶/果汁/水/蛋糕/鸡蛋/饼干）
6. **可数不可数初步**：some + 不可数名词（some milk/bread）；可数加 s（some eggs）
7. **核心句型**：What do you like? → I like...；What do we have? → We have some...
8. **交际功能**：谈论喜欢的动物玩具、表达食物需求

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| like + 复数名词 | I like + 名词复数（表一类） | 表达长期喜好 |
| 名词复数 +s/es | 一般+s；s/x/ch/sh+es；辅音+y→ies 初步 | 两个及以上 |
| some 的用法 | some + 可数复数/不可数名词 | 表达"一些" |
| 不可数名词 | milk, water, juice, bread, rice 不加 s，用 some 修饰 | 液体与物质名词 |
| 否定句 | I don't like... | 表达不喜欢 |

## 三、解题方法
1. **复数意识法**：like 后面想"一类东西"，名词记得加 s
2. **可数不可数判断法**：液体、肉类、面包类一般不可数
3. **分类记忆法**：动物/玩具/食物三类单词分开做成卡片
4. **问答匹配法**：What do you like? → I like...s
5. **some 填空法**：some 后面要么加复数要么加不可数名词

## 六、常见考点
1. 名词复数拼写：tiger—tigers, bus—buses
2. 单项选择：I like ___（panda/pandas）
3. some 后面名词形式：some ___（milk/milks）
4. 问答匹配：What do you like? → I like...
5. 听力：选出听到的动物或玩具
6. 看图写话：I like... I don't like...
