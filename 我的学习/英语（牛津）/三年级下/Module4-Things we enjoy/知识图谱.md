## 一、核心概念
1. **卡通人物词汇**：cartoon, mouse, cat, superman, hero（卡通/老鼠/猫/超人/英雄）；funny, cute（滑稽的/可爱的）
2. **能力句型 can**：He can fly. / She can run fast.（他会飞/她跑得快）
3. **can 的疑问与否定**：Can you swim? → Yes, I can. / No, I can't.（can 后动词用原形）
4. **母亲节词汇**：Mum, flower, card, gift, love（妈妈/花/卡片/礼物/爱）
5. **节日祝福**：Happy Mother's Day! I love you, Mum.（母亲节快乐！我爱你，妈妈）
6. **故事词汇（三只小猪）**：pig, wolf, house, straw, wood, brick（猪/狼/房子/稻草/木头/砖）
7. **故事句型**：Little pig, little pig, let me come in! / No, no, no!（小猪让我进来！/不不不！）
8. **交际功能**：谈论卡通人物能力、表达节日祝福、复述简单故事

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| can 表能力 | 主语 + can + 动词原形（无人称变化） | 表达会做某事 |
| can 一般疑问句 | Can + 主语 + 动词原形? → Yes, ...can. / No, ...can't. | 询问能力 |
| can 否定式 | can't = cannot，后仍接动词原形 | 表达不会做 |
| 祝福句型 | Happy + 节日名! | 节日表达祝福 |
| 故事叙述 | 用简单句按顺序讲：First... Then... | 复述故事初步 |

## 三、解题方法
1. **can 后原形检查法**：做完题回头检查 can 后面是不是动词原形
2. **问答一致法**：Can 问 Can 答，Yes 后接 can，No 后接 can't
3. **人物特征记忆法**：Superman can fly / The mouse is small 配对记
4. **故事排序法**：按起因→经过→结果给故事图片排序
5. **角色表演法**：三人一组演三只小猪，边演边记台词
