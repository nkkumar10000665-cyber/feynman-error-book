## 一、核心概念
1. **玩具词汇**：doll 洋娃娃、ball 球、kite 风筝、robot 机器人、toy car 玩具车。
2. **喜好句型**：I like + 名词.（我喜欢……），如 I like dolls.
3. **食物词汇**：rice 米饭、noodles 面条、egg 鸡蛋、meat 肉、fish 鱼。
4. **喜好问答句型**：Do you like + 名词? — Yes, I do. / No, I don't.
5. **饮料词汇**：milk 牛奶、water 水、juice 果汁、cola 可乐。
6. **分类概念**：food 食物 vs drinks 饮料，注意区分。
7. **交际功能**：表达个人喜好并询问他人喜好。

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 表达喜好 | I like + 名词. | 说明自己喜欢的东西 |
| 喜好问答 | Do you like ...? — Yes, I do. / No, I don't. | 询问别人是否喜欢 |
| 否定回答 | No, I don't. | 不喜欢时礼貌回答 |
| like+复数 | I like + 可数名词复数. | 泛指喜欢一类东西 |
| 一日三餐表达 | I like rice for lunch. | 谈论饮食喜好 |

## 三、解题方法
1. **实物分类游戏**：把食物卡片和饮料卡片分两队，边分边说单词。
2. **调查表操练**：问同学 Do you like milk? 记录 Yes/No，练真实交际。
3. **表情联想法**：笑脸配 I like ...，哭脸配 I don't like ...。
4. **听音选图**：听玩具单词，在图片中找出对应玩具。
5. **句型替换操练**：Do you like 后面换食物、饮料、玩具反复问答。
