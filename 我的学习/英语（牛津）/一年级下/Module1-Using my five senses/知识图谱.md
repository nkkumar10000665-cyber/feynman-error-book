## 一、核心概念
1. **视觉句型**：I can see + 事物.（我能看见……），如 I can see a bird.
2. **听觉句型**：I can hear + 事物.（我能听见……），如 I can hear a dog.
3. **声音相关词汇**：bird 鸟、dog 狗、car 汽车、bus 公交车、cat 猫。
4. **味觉形容词**：sweet 甜的、sour 酸的、yummy 好吃的。
5. **描述味道句型**：It's + 味道形容词.（它是……的），如 It's sweet.
6. **感官词汇**：eye 眼睛→see 看、ear 耳朵→hear 听、nose 鼻子→smell 闻、mouth 嘴→taste 尝。
7. **食物词汇（复用扩展）**：candy 糖果、lemon 柠檬、ice cream 冰淇淋。

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 视觉表达 | I can see + 事物. | 描述眼睛看到的东西 |
| 听觉表达 | I can hear + 事物. | 描述耳朵听到的声音 |
| 味觉描述 | It's sweet / sour. | 品尝食物后描述味道 |
| 感官问答 | What can you see? — I can see a ... | 问答看见的事物 |
| can 的用法 | can + 动词原形 | 表达能力或感官结果 |

## 三、解题方法
1. **TPR动作记忆法**：指眼睛说 see、指耳朵说 hear，动作绑定感官动词。
2. **听音辨物**：闭上眼睛听声音，说出 I can hear a dog.
3. **实物品尝法**：尝糖果说 It's sweet. 尝柠檬说 It's sour.
4. **图片联想法**：看窗外图片说出 I can see a bus.
5. **句型替换操练**：I can see / hear 后面换不同事物反复练习。
