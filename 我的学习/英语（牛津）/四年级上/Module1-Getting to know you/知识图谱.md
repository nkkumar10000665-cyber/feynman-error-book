## 一、核心概念

1. **自我介绍词汇**：name（名字）、age（年龄）、class（班级）、grade（年级）、new（新的）、friend（朋友）——用于开学认识新朋友。
2. **介绍句型**：Hello, I'm ... / My name is ...（我叫……）；I'm ten.（我十岁）；I'm in Class 3, Grade 4.（我在四年级三班）。
3. **能力词汇**：swim（游泳）、run（跑步）、jump（跳）、fly（飞）、write（写）、read（读）。
4. **能力问答句型**：Can you swim? — Yes, I can. / No, I can't.；第三人称：He/She can swim. / He can't fly.（can 后动词用原形）。
5. **情绪词汇**：happy（开心）、sad（难过）、tired（累）、hungry（饿）、thirsty（渴）、full（饱）。
6. **感受问答句型**：Are you happy? — Yes, I am. / No, I'm not.；How do you feel? — I'm tired.（询问并表达感受）。
7. **交际功能**：初次见面打招呼、询问和介绍个人信息、谈论会与不会做的事、询问和表达情绪感受。

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 情态动词 can | can + 动词原形；否定 can't + 原形 | 谈论能力，所有人称通用 |
| 一般疑问句 can | Can + 主语 + 动词原形 …? 回答 Yes, … can. / No, … can't. | 询问能力 |
| be 动词搭配 | I am / you are / he is / she is / it is | 描述状态、感受、身份 |
| 第三人称单数初步 | He/She can …；He is …（be 随人称变化） | 谈论他人时 |

## 三、解题方法

1. **人物定位法**：先看主语是 I / you / he / she，再确定 be 动词用 am / are / is。
2. **can 句型三步走**：一找 can（肯定/否定/疑问），二定动词用原形，三按人称组织问答。
3. **情景应答匹配**：听到 How do you feel? 找情绪词回答；听到 Can you …? 找 Yes/No + can/can't。
4. **词块记忆法**：把 meet new people、in Class 3、feel tired 当整块记，不拆词。

## 六、常见考点

1. 选择题：I ___ ten.（am/are/is 辨析）。
2. 句型转换：I can swim. → 一般疑问句及肯否回答。
3. 情景对话：新同学见面如何自我介绍。
4. 看图写话：用 happy/sad/tired 描述人物感受。
5. 阅读理解：判断短文人物的年龄、班级、会做的事。
