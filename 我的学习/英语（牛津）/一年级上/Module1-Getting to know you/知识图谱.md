## 一、核心概念
1. **问候用语**：Hello 你好 / Hi 嗨 / Good morning 早上好，见面打招呼时使用。
2. **自我介绍句型**：I'm + 名字.（我是……），如 I'm Kitty.
3. **介绍他人句型**：This is + 人名.（这是……），如 This is Danny.
4. **五官词汇**：face 脸、eye 眼睛、nose 鼻子、mouth 嘴、ear 耳朵。
5. **指认部位句型**：This is my + 五官名词.（这是我的……），如 This is my nose.
6. **人物称呼**：teacher 老师、classmate 同学、boy 男孩、girl 女孩。
7. **课堂指令**：Stand up. 起立 / Sit down. 坐下 / Open your book. 打开书。

## 三、解题方法
1. **TPR动作记忆法**：边指自己的五官边说 This is my eye，用动作带动单词记忆。
2. **图片联想法**：看到人物图片就说出 This is ...，把单词和画面绑定。
3. **句型替换操练**：把 I'm 后面替换成不同名字反复练，做到脱口而出。
4. **听音选图**：听单词（eye / nose / mouth），在几张图片中选出对应部位。
5. **角色扮演**：两人一组互相问候并自我介绍，模拟开学第一天场景。
