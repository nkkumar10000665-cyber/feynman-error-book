## 一、核心概念
1. **家庭成员扩展词汇**：grandfather / grandmother (grandpa / grandma)、cousin 堂（表）兄弟姐妹、uncle 叔叔、aunt 阿姨（U4）
2. **频度副词**：always 总是、usually 通常、often 经常、sometimes 有时、never 从不（U4 核心语法）
3. **与祖父母活动**：visit my grandparents、go to the park、play chess、cook dinner（U4 话题短语）
4. **朋友异同句型**：We both like ... 我们俩都喜欢……；We both have ... （U5 核心交际功能）
5. **both 与 all**：both 用于两者，all 用于三者及以上（U5 辨析重点）
6. **描述朋友**：the same 相同的 / different 不同的；like doing sth 喜欢做某事（U5）
7. **家庭生活场景词汇**：living room 客厅、kitchen 厨房、bedroom 卧室、bathroom 浴室；do homework、watch TV（U6）
8. **现在进行时**：be + 动词-ing，表示"正在做……"，如 I am doing my homework.（U6 复习巩固）

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 频度副词位置 | 频度副词放在 be 动词后、实义动词前：He is always busy. / She usually visits us. | 描述习惯性动作的频率，用一般现在时 |
| 频度问答 | How often do you ...? — I usually / often ... | 询问做某事的频率 |
| both 用法 | We both like ... / They both have ... | 主语为两个人（或两个事物）时 |
| all 用法 | We all like ... | 主语为三个及以上的人或事物时 |
| both/all 位置 | 放在 be 动词后、实义动词前：We are both ten. / We both like reading. | 与频度副词位置规则相同 |
| 现在进行时 | 主语 + be (am/is/are) + 动词-ing | 描述说话时或现阶段正在发生的动作 |
| 动词-ing 变化 | 一般加 -ing；去 e 加 -ing（make→making）；双写尾字母（run→running, sit→sitting） | 重读闭音节结尾才双写 |

## 三、解题方法
1. **动词判类定位法**：句中有 be 动词（is/are），频度副词和 both 放其后；有实义动词，放其前——先找动词类型再填空。
2. **人数判断法**：题目出现两个名字用 both，三个及以上用 all，先在题干中数人数。
3. **时态标志词定位法**：看到 now / Look! / Listen! 立刻判断用现在进行时，动词变 -ing。
4. **思维导图记话题词汇**：以 family members / activities / rooms 为中心词整理本模块词汇。
5. **对比写作法**：写 My Friend and I 时用"相同点（both like）→ 不同点（I like... but he likes...）"两段式。

## 六、常见考点
1. 单项选择：频度副词和 both / all 在句中的位置。
2. 用所给词的适当形式填空：动词 -ing 变化（去 e、双写规则是易错点）。
3. both 与 all 的辨析选择（数清人数是关键）。
4. 句型转换：一般现在时句子改写成现在进行时（加 be、变动词）。
5. 阅读理解：介绍家庭成员或朋友的短文细节判断（True or False）。
6. 书面表达：My Good Friend 或 My Family Life 小短文（5-6 句话）。
