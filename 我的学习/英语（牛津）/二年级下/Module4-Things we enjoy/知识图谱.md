## 一、核心概念

1. **活动词汇（动词-ing）**：playing 玩、running 跑、skipping 跳绳、swimming 游泳、flying a kite 放风筝。
2. **活动句型**：I like playing. / We are playing.（谈论喜欢或正在进行的活动。）
3. **读书日表达**：Book Day 读书日；I like this book. It's fun.（我喜欢这本书，很有趣。）
4. **图书词汇**：book 书、storybook 故事书、picture book 图画书。
5. **故事人物**：Goldilocks 金发姑娘、three bears 三只熊（Father Bear、Mother Bear、Baby Bear）。
6. **故事句型**：This bed is too hard/soft. This bed is just right.（这张床太硬/软，这张正好。）
7. **交际功能**：谈论娱乐活动、分享图书、简单复述童话故事。

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| like + doing | I like + 动词-ing. | 表达喜欢的活动 |
| 评价事物 | It's fun/nice/great. | 评价书或活动 |
| 比较描述 | This + 物品 + is too + 形容词. | 故事中描述不合适 |
| 正好表达 | This one is just right. | 故事中表示刚刚好 |

## 三、解题方法

1. **TPR动作记忆**：做跳绳、游泳动作说 skipping/swimming。
2. **故事表演法**：三人一组扮演三只熊和金发姑娘表演故事。
3. **图片排序法**：把故事图片按顺序排列并复述。
4. **句型替换操练**：This bed is too hard. 替换 chair/soup 等词。
5. **听音选图**：听 I like reading storybooks. 选对应图片。

## 六、常见考点

1. 单项选择：I like ____.（play/playing 选 playing）
2. 应答配对：What do you like? — I like storybooks.
3. 故事排序：金发姑娘故事图片排序题。
4. 填空：This bed is too ____.（hard/soft）
5. 易错点：too 与 just right 的对比使用；play 后接球类不加 the。
6. 情景交际：Book Day 向同学推荐一本书。
