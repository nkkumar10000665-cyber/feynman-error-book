## 一、核心概念

1. **视觉句型 What can you see?**：What can you see? — I can see a ship.（你能看见什么？我能看见一艘船。）
2. **视觉词汇**：ship 轮船、kite 风筝、balloon 气球、rainbow 彩虹。
3. **触觉表达 Touch and feel**：Touch it. How does it feel? — It's hard/soft/smooth.（摸一摸，感觉如何？）
4. **触觉词汇**：hard 硬的、soft 软的、smooth 光滑的、rough 粗糙的。
5. **听觉句型 Can you hear...?**：Can you hear a train? — Yes, I can. / No, I can't.（你能听见火车声吗？）
6. **听觉词汇**：train 火车、plane 飞机、car 汽车、bell 铃声、drum 鼓。
7. **交际功能**：用五种感官（看、摸、听）描述周围世界。

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 询问所见 | What can you see? — I can see + a + 事物. | 问能看见什么 |
| 询问触感 | How does it feel? — It's + 触感形容词. | 摸东西描述感觉 |
| 询问所听 | Can you hear + a + 声音来源? — Yes, I can. / No, I can't. | 问能否听见某声音 |
| 祈使句引导 | Touch it. / Listen! | 引导别人摸/听 |

## 三、解题方法

1. **实物触摸法**：摸铅笔盒、毛绒玩具说 hard/soft。
2. **听音辨物**：闭眼听声音猜是 train 还是 plane。
3. **句型替换操练**：What can you see? 替换不同事物反复问答。
4. **图片联想法**：看彩虹图片说 I can see a rainbow.
5. **分类记单词**：按"看到的/摸到的/听到的"三类整理单词卡。

## 六、常见考点

1. 应答配对：What can you see? — I can see a kite.
2. 单项选择：Can you ____ a train?（hear/see 辨析）
3. 听音选图：根据听到的声音选交通工具。
4. 填空：Touch the desk. It's ____.（hard）
5. 易错点：hear（听见）与 see（看见）混淆；feel 后接形容词。
6. 情景交际：蒙眼摸物游戏对话。
