## 一、核心概念

1. **喜欢做某事 like + doing**：I like swimming.（我喜欢游泳。）like 后接动词 -ing 形式。
2. **活动词汇**：swimming 游泳、running 跑、dancing 跳舞、singing 唱歌、reading 阅读、drawing 画画。
3. **询问喜好 What do you like doing?**：What do you like doing? — I like reading.（你喜欢做什么？）
4. **食物词汇**：bread 面包、egg 鸡蛋、milk 牛奶、juice 果汁、cake 蛋糕、ice cream 冰淇淋。
5. **动物喜好表达**：I like dogs. They're cute.（我喜欢狗，它们可爱。）
6. **动物词汇**：dog 狗、cat 猫、bird 鸟、fish 鱼、rabbit 兔子、monkey 猴子。
7. **交际功能**：谈论自己喜欢做的事、喜欢吃的食物、喜欢的动物。

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| like + doing | I like + 动词-ing. | 表达喜欢做某事 |
| 询问喜好 | What do you like doing? — I like... | 问对方爱好 |
| like + 名词 | I like + 名词（可数用复数）. | 表达喜欢某物/动物 |
| 补充评价 | They're cute/nice. / It's yummy. | 说明喜欢的理由 |

## 三、解题方法

1. **TPR动作记忆**：做动作说 I like swimming/dancing.
2. **调查表格法**：采访同学喜欢什么，填表汇报。
3. **句型替换操练**：I like reading. 替换不同活动词。
4. **图片联想法**：看食物图片说 I like cake. It's yummy.
5. **听音选图**：听 I like monkeys. 选猴子图片。

## 六、常见考点

1. 单项选择：I like ____.（swim/swimming 辨析，选 swimming）
2. 应答配对：What do you like doing? — I like singing.
3. 看图写话：用 I like... 描述喜欢的动物。
4. 听音选图：区分不同活动单词。
5. 易错点：like 后动词要加 -ing；动物名词复数表一类（I like dogs）。
6. 情景交际：朋友介绍自己喜欢的东西。
