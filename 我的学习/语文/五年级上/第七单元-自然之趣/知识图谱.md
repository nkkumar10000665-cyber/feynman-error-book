## 一、核心概念

1. **自然之趣（人文主题）**：本单元以"四季景物"为主题，从古诗词到现代散文，描绘大自然不同季节、不同时刻的独特韵味。"四时景物皆成趣。"
2. **静态描写与动态描写（语文要素）**：初步体会课文中的静态描写和动态描写——静态描写写事物静止时的样子，动态描写写事物运动变化时的情景，两者结合使景物有声有色、有静有动。
3. **《山居秋暝》要点**：王维山水诗，"明月松间照，清泉石上流"，描绘秋雨初晴后傍晚山村的风光，寄托诗人高洁的情怀和对隐居生活的满足。
4. **《枫桥夜泊》要点**：张继写秋夜泊船枫桥所见所闻，"月落乌啼霜满天，江枫渔火对愁眠"，"夜半钟声"衬托旅途的孤寂忧愁。
5. **《长相思》要点**：纳兰性德的词，"山一程，水一程""风一更，雪一更"，写行军途中的风雪声搅碎了思乡之梦，表达深深的羁旅思乡之情。
6. **《四季之美》要点**：清少纳言（日本）写春天黎明、夏天夜晚、秋天黄昏、冬天早晨各自最美的时刻与景致，感受作者对自然、对生活的热爱。
7. **《鸟的天堂》要点**：巴金两次经过"鸟的天堂"——傍晚看大榕树（静态：枝繁叶茂、生机勃勃），早晨看群鸟纷飞（动态：百鸟欢腾），赞美南国风光与生命活力。
8. **《月迹》要点**：贾平凹写中秋夜孩子们寻月的过程，月亮无处不在，启迪我们：美好的事物属于每一个人，要努力去追求。

## 二、公式与定理（规则与方法）

| 名称 | 内容/规则 | 适用条件 |
|---|---|---|
| 静态描写 | 写景物相对静止时的形态、色彩、位置，如"那么多的绿叶，一簇堆在另一簇上面" | 表现景物宁静、整体之美 |
| 动态描写 | 写景物运动变化时的动作、声音、姿态，如"大的，小的，花的，黑的，有的站在树枝上叫……" | 表现景物活力与生机 |
| 动静结合 | 先静后动或以动衬静，画面有声有色，如《鸟的天堂》两次所见 | 写景文章阅读与写作 |
| 以动衬静 | 用声音、动作反衬环境幽静，如"蝉噪林逾静，鸟鸣山更幽" | 体会意境的幽静 |
| 借景抒情 | 诗人把情感融入景物，景中含情，如"江枫渔火对愁眠"的"愁" | 古诗词鉴赏 |

## 三、解题方法

1. **动静辨析法**：判断句子是静态还是动态描写——看有没有动作、声音、变化；再体会这样写的好处（静显安宁，动显活力）。适用于本单元核心考点。
2. **想象画面法**：读诗词散文时闭眼想象画面（时间、地点、景物、色彩、声音），用自己的话描述出来。适用于"想象诗句描绘的景象"题。
3. **抓诗眼词眼法**：找出最能传情的字（"愁""碎""空"），体会它在全诗中的作用。适用于古诗词情感体会。
4. **时间顺序梳理法**：按时间变化梳理景物（黎明→夜晚→黄昏→早晨；傍晚→早晨），体会不同时刻不同的美。适用于《四季之美》《鸟的天堂》。
5. **朗读体悟法**：静态部分读得舒缓，动态部分读得轻快，通过朗读节奏变化体会动静之美。适用于有感情朗读题。

## 六、常见考点

1. 古诗词三首的背诵默写与诗意理解（尤其"明月松间照""月落乌啼霜满天"）。
2. 判断并赏析句子的静态描写或动态描写。
3. 想象并描述诗句/文段描绘的画面。
4. 《鸟的天堂》两次经过所见之景的不同（静：大榕树；动：众鸟纷飞）及表达的感情。
5. 按时间顺序梳理《四季之美》中每个季节最美的时刻。
6. 重点字词与多音字（"更""泊""晕""悄"）及日积月累《渔歌子》。
