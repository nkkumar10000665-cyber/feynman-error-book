## 一、核心概念

1. **民间故事（人文主题）**：民间故事是老百姓口耳相传的经典，是劳动人民智慧的结晶。本单元三篇课文都是动人的民间故事，情节曲折，充满想象，寄托着人们朴素的愿望。
2. **创造性复述（语文要素）**：了解课文内容，创造性地复述故事——可以变换人称（如以海力布或乡亲的口吻讲）、合理想象增加细节、变换情节顺序（先讲结局设悬念），但不能改变故事主要内容和人物品质。
3. **《猎人海力布》要点**：猎人海力布为救乡亲们说出动物的话，违背白蛇的叮嘱变成石头，赞美他热心助人、舍己为人的品质。
4. **《牛郎织女（一）》要点**：牛郎从小受哥嫂虐待，与老牛相依为命，在老牛帮助下与织女结为夫妻，表现勤劳善良的牛郎和追求自由的织女。
5. **《牛郎织女（二）》要点**：织女被抓回天庭，牛郎挑着儿女追赶，王母划天河阻隔，二人化作牵牛星、织女星，每年农历七月初七鹊桥相会，表达人们对美好生活的向往。
6. **重点字词**：酬谢、珍宝、叮嘱、崩塌、焦急、发誓、谎话、迟延、后悔、嫂子、稀罕、纱衣、妻子、一趟、酿酒、勤勤恳恳、眉开眼笑等。
7. **习作：缩写故事**：把内容较复杂的长故事缩写成简短的故事——摘录、删减、概括、改写，保留主要情节，删去次要内容，做到故事完整、情节连贯、语句通顺。
8. **快乐读书吧**：《中国民间故事》整本书阅读，推荐阅读《田螺姑娘》《梁山伯与祝英台》《八仙过海》等。

## 二、公式与定理（规则与方法）

| 名称 | 内容/规则 | 适用条件 |
|---|---|---|
| 变换人称复述 | 以故事中人物的口吻讲，如以海力布的口吻讲"我"的经历 | 创造性复述练习 |
| 增加细节复述 | 在不改变原意的前提下，合理想象人物的语言、动作、心理 | 把简略处讲具体 |
| 变换顺序复述 | 先讲结局设置悬念，再从头讲起，吸引听众 | 讲故事比赛 |
| 摘录法（缩写） | 直接保留原文重要的句子（如交代结果、点明中心的句子） | 缩写关键情节 |
| 删减法（缩写） | 删去次要人物、次要情节和修饰性语句 | 压缩篇幅 |
| 概括改写（缩写） | 把人物大段对话改为叙述，把详细描写概括为简要交代 | 对话多、描写细的部分 |

## 三、解题方法

1. **情节梳理法**：用示意图或小标题梳理故事脉络（救白蛇→得宝石→听消息→劝乡亲→变石头），理清起因经过结果。适用于把握课文内容。
2. **创造性复述三步法**：熟记主要情节→确定创造点（换人称/加细节/调顺序）→绘声绘色地讲。适用于口语交际和复述题。
3. **缩写四步法**：读通原文→分清主次→用摘录、删减、概括、改写压缩→连缀成文、读顺检查。适用于习作《缩写故事》。
4. **人物品质分析法**：抓住人物做了什么事、说了什么话，用一两个词概括品质（舍己为人、勤劳善良、敢于追求幸福）。适用于评价人物题。

## 六、常见考点

1. 看拼音写词语、多音字（如"没""落""拗"）。
2. 按顺序梳理并复述故事情节（海力布变石头、牛郎织女鹊桥会）。
3. 创造性复述：变换人称或增加细节讲一段故事。
4. 评价人物品质并说明理由。
5. 缩写故事习作：保留主干、删减概括、情节连贯。
6. 日积月累：背诵《乞巧》（林杰），了解七夕节与民间故事的联系。
