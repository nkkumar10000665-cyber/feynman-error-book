## 一、核心概念

1. **把事情写清楚**：本单元语文要素。按一定顺序，写清事情的起因、经过、结果，重点部分写具体。
2. **《麻雀》要点**：屠格涅夫写老麻雀在猎狗面前奋不顾身保护小麻雀，表现伟大的母爱；作者把"看到的、听到的、想到的"写得很清楚。
3. **《爬天都峰》要点**："我"和老爷爷互相鼓励爬上天都峰，按"爬山前—爬山中—爬上峰顶后"的顺序写清过程。
4. **习作单元结构**：精读课文（学方法）→交流平台（总结方法）→初试身手（练一练）→习作例文→单元习作。
5. **写清楚三招**：①按事情发展顺序写；②把起因、经过、结果交代清楚；③把重要内容（怎么想、怎么说、怎么做）写具体。
6. **重点字词**：嗅觉、发呆、鸟巢、牙齿、身躯、掩护、幼儿、搏斗、庞大、力量、愣住、石级、铁链、发颤、攀爬、猴子、鲫鱼、纪念、辫子、笑呵呵、鼓舞、居然。

## 二、规则与方法

| 名称 | 内容/规则 | 适用条件 |
| --- | --- | --- |
| 事情发展顺序法 | 按起因→经过→结果（或事前→事中→事后）组织材料 | 写一件事 |
| 六要素交代法 | 时间、地点、人物、起因、经过、结果交代完整 | 叙事类阅读与习作 |
| 重点部分放大法 | 把经过中最重要的部分写具体：动作+语言+心理 | 习作重点段 |
| "看到的+听到的+想到的" | 学习《麻雀》，三方面结合把场面写清楚 | 写紧张、感人场面 |
| 交流平台归纳法 | 从课文中归纳写法，迁移到自己的习作 | 单元学习 |

## 三、解题方法

1. **写作顺序题**：找标志词（爬山前、爬山中、爬上峰顶后），判断顺序类型。
2. **内容概括题**：用"起因+经过+结果"一句话概括（如《麻雀》：猎狗想吃小麻雀，老麻雀拼死保护，猎狗退缩）。
3. **写法分析题**：问"作者怎样把事情写清楚的"，从顺序、详略、人物描写三方面答。
4. **句子体会题**：如"像一块石头似的落在猎狗面前"，体会比喻写出老麻雀的坚决。
5. **习作"生活万花筒"**：选一件印象深刻的事→列起因经过结果提纲→重点部分写具体→表达真情实感。

## 六、常见考点

1. 概括课文主要内容（起因、经过、结果）。
2. 分析《麻雀》中老麻雀的动作、作者"想到的"句子的作用。
3. 《爬天都峰》写作顺序及"我"与老爷爷互相道谢的原因。
4. 按事情发展顺序给句子排序。
5. 看拼音写词语、形近字辨析（"级/极""辫/辨"）。
6. 习作：生活万花筒，写清事情经过，重点部分具体。
