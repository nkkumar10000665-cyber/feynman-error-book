## 一、核心概念

1. **提问策略**：本单元语文要素。阅读时主动从不同角度提出问题，问题越多，思考越深；提问能帮助我们理解课文。
2. **提问的三个角度**：①针对课文内容提问；②针对写法（为什么这么写）提问；③从课文中得到启示、联系生活经验提问。
3. **《一个豆荚里的五粒豆》要点**：五粒豆不同的命运，第五粒豆给生病的小女孩带来生的希望；学习针对全文和部分内容提问。
4. **《夜间飞行的秘密》要点**：蝙蝠靠嘴和耳朵配合探路，科学家据此发明雷达；学习从内容、写法、启示多角度提问。
5. **《呼风唤雨的世纪》要点**：20世纪科学技术改变了人类生活，"呼风唤雨"指人类利用科技改造自然；学习筛选对理解课文最有帮助的问题。
6. **《蝴蝶的家》要点**：作者为雨天蝴蝶躲在哪里而着急、猜想、寻找，表达对幼小生命的关爱；综合运用提问策略。
7. **重点字词**：豌豆、按照、舒适、恐怕、僵硬、耐心、愉快、雷达、蚊子、即使、灵巧、科学家、横七竖八、研究、驾驶、世纪、技术、改变、程度、超过、幻想。

## 二、规则与方法

| 名称 | 内容/规则 | 适用条件 |
| --- | --- | --- |
| 多角度提问法 | 从内容、写法、启示三个角度提问，写在课文相应位置 | 所有课文阅读 |
| 问题清单整理法 | 先列出所有问题，再合并同类、删去不影响理解的问题 | 小组学习、课后整理 |
| 问题筛选法 | 保留"能帮助我们理解课文"的问题优先解决 | 说明类课文 |
| 边读边问法 | 不妨碍理解的情况下，有疑问随手批注，读完再整理 | 自主阅读 |
| 借问题理解法 | 带着问题再读课文，从文中找答案或讨论解决 | 精读环节 |

## 三、解题方法

1. **提问角度判断题**：看问题指向——问"写了什么/为什么这样"是内容角度；问"为什么这么写/用了什么方法"是写法角度；问"对我有什么启发"是启示角度。
2. **自主提问题**：先读懂一段，再模仿"是什么、为什么、怎么样、如果……会怎样"句式提2-3个问题。
3. **筛选问题题**：问自己"解决这个问题能帮我读懂课文吗？"能→保留；不能→删去。
4. **联系生活解决题**：结合生活经验或查资料回答自己提出的问题（如"为什么蝙蝠夜里飞行不会撞东西"）。
5. **习作"小小'动物园'"**：把家人比作动物，抓住相似之处（外貌、性格、爱好）写清楚。
