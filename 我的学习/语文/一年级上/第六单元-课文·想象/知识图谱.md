## 一、核心概念

1. **《影子》**：认识前、后、左、右方位词，知道影子跟着人走的现象，激发观察兴趣。
2. **《比尾巴》**：问答式儿歌，知道猴子、兔子、松鼠、公鸡、鸭子、孔雀尾巴的特点，会朗读问答句。
3. **《青蛙写诗》**：初步认识逗号、句号、省略号，知道小蝌蚪、水泡泡、水珠当标点。
4. **《雨点儿》**：大雨点儿和小雨点儿去不同地方，带来不同变化，初步感知雨水与植物的关系。
5. **本单元生字词**：会写"在、后、我、好、长、比、巴、把、下、个、雨、们、问、有、半、从、你"等。
6. **问答句式与想象**：读好问句，学习用完整的句子回答问题。

## 二、公式与定理（规则与方法）

| 名称 | 内容/规则 | 适用条件 |
| --- | --- | --- |
| 标点符号初步 | 逗号（，）表示句子中间停顿；句号（。）表示一句话说完；省略号（……）表示话没说完 | 朗读、数句子 |
| 疑问句朗读 | 问句句末语调上扬，读出疑问语气 | 朗读《比尾巴》 |

| 完整句式 | 谁+干什么 / 什么+怎么样，把句子说完整 | 说话、回答问题 |
| 问答对应 | 问什么答什么，答句与问句内容对应 | 问答练习 |

## 三、解题方法

1. **分角色朗读法**：一人读问句、一人读答句，读出问答语气。适用于《比尾巴》。
2. **图文对照法**：借助插图理解影子方位、尾巴特点。适用于理解课文内容。
3. **提问回答法**：自问自答"谁的尾巴长？猴子的尾巴长"。适用于巩固内容。
4. **联系生活想象法**：想想生活中影子什么时候出现。适用于《影子》。
5. **找标点数句子**：以句号、问号、感叹号为标志数出一共有几句话。适用于课文理解题。

## 六、常见考点

1. 按课文内容填空（谁的尾巴（ ）？）。
2. 数出课文有几句话。
3. 动物与尾巴特点连线。
4. 给句子加标点（，。？）。
5. 看拼音写汉字。
6. 照样子写完整句子。
