## 一、核心概念

1. **学科词汇**：English（英语）、Chinese（语文）、Maths（数学）、Music（音乐）、Art（美术）、PE（体育）
2. **爱好活动词汇**：reading（阅读）、singing（唱歌）、drawing（画画）、dancing（跳舞）、playing（玩耍）
3. **重点句型1：I like + 学科**：I like English.（我喜欢英语。）
4. **重点句型2：I like + doing**：I like reading.（我喜欢读书。）like 后面的动词要加 -ing
5. **问答句型**：What do you like? — I like singing.（你喜欢什么？）
6. **交际功能**：谈论自己喜欢的学科和业余活动，学会表达个人喜好

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| like + doing | like 后面接动词的 -ing 形式，表示"喜欢做某事" | 表达爱好、习惯，如 I like reading. |
| like + 名词 | like 后面直接接名词（学科、事物） | 表达喜欢某物，如 I like English. |
| What do you like? | 用 What 提问喜好，用 I like... 回答 | 询问别人喜欢什么 |

## 三、解题方法

1. **看图选词法**：看到课本插图先想对应的学科或活动单词，再拼写。
2. **句型替换法**：用"I like ___"做替换练习，把不同学科、活动词套进句型。
3. **-ing 检查法**：做完题检查 like 后面的动词是否加了 -ing（read→reading）。
4. **问答配对法**：把"What do you like?"和答句连线，注意人称一致。

## 六、常见考点

1. 学科词汇拼写（English, Chinese, Maths 首字母大写）。
2. like 后面动词加 -ing 的填空题（I like ___ (read)）。
3. "What do you like?" 的问答题。
4. 听力：听句子选出对应的学科或活动图片。
5. 连词成句：like / I / reading (.) → I like reading.
