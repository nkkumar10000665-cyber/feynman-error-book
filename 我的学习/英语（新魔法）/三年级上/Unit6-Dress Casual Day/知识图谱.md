## 一、核心概念

1. **服装词汇**：jeans（牛仔裤）、sweater（毛衣）、jacket（夹克）、uniform（校服）、trainers（运动鞋）、boots（靴子）
2. **场合词汇**：party（聚会）、school（学校）、sports day（运动日）、picnic（野餐）
3. **重点句型1：should 表建议**：You should wear a uniform.（你应该穿校服。）
4. **重点句型2：should 否定**：You shouldn't wear jeans to school.（你不应该穿牛仔裤上学。）
5. **问答句型**：What should I wear? — You should wear...（我应该穿什么？）
6. **交际功能**：根据不同场合给别人穿衣建议，讨论着装是否合适

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| should + 动词原形 | should 后面直接跟动词原形 | 提出建议，如 You should wear a jacket. |
| shouldn't + 动词原形 | should not = shouldn't，后面跟动词原形 | 表示"不应该"，如 You shouldn't run. |
| What should I...? | 用 What should I wear/do? 征求意见 | 向他人询问建议 |

## 三、解题方法

1. **原形检查法**：should/shouldn't 后面的动词必须是原形，不加 s、不加 -ing。
2. **场合配对法**：先把场合（party/school/sports day）和合适服装连线，再写句子。
3. **正反建议法**：同一个场合练习两种说法——应该穿什么、不应该穿什么。
4. **缩写记忆法**：should not = shouldn't，注意拼写中多了一个 n。
