## 一、核心概念
1. **乡村事物词汇**：farm 农场、tree 树、flower 花、grass 草、river 小河、hill 小山、sky 天空、cloud 云
2. **农场动物词汇**：duck 鸭子、hen 母鸡、cow 奶牛、sheep 绵羊、horse 马
3. **重点句型-单数存在**：There is a...（有一个……）
4. **重点句型-复数存在**：There are...（有一些/许多……）
5. **重点句型-看的事物**：Look! There is a duck on the river.（看！河上有只鸭子）
6. **交际功能**：描述乡村/农场里看到的事物，初步用 There be 表达"某处有某物"

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| There is 句型 | There is a/an + 单数名词 (+ 方位). | 某处有一个事物时用 |
| There are 句型 | There are + 数字/复数名词 (+ 方位). | 某处有多个事物时用 |
| is/are 选择规则 | 后面名词是单数用 is，复数用 are | There is a cow. / There are two cows. |
| 与方位结合 | There be + 名词 + 方位介词短语 | There is a duck on the river. |

## 三、解题方法
1. **图片联想法**：一幅乡村大图，指图说 There is a tree. / There are flowers.
2. **数数定 is/are**：先数图中数量，1 个用 There is，多个用 There are
3. **句型替换操练**：固定 There is/are...，替换名词与方位反复练
4. **听音选图技巧**：听清 is 还是 are 及名词，判断数量后选图
5. **看图说话三步**：一看场景→二数数量→三说 There be 整句

## 六、常见考点
1. 听音选图：听到 There are three ducks. 选三只鸭子的图
2. 单词英汉配对：river—小河、sheep—绵羊
3. 选词填空：There ___ a cow on the farm.（is/are）
4. 看图选句：一朵花选 There is a flower.
5. 句型转换感知：There is a tree. → There are two trees.
