## 一、核心概念
1. **动作词汇**：sing 唱歌、dance 跳舞、jump 跳、run 跑、swim 游泳、draw 画画、read 读、fly 飞
2. **能力词汇**：can 能、会
3. **重点句型-表达能力**：I can + 动词.（我会……）
4. **重点句型-询问能力**：Can you + 动词?（你会……吗？）
5. **重点句型-回答**：Yes, I can. / No, I can't.（是的，我会。/ 不，我不会）
6. **交际功能**：谈论自己会做的事情，并询问同伴的能力

## 二、公式与定理
| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 表达能力句型 | I can + 动词原形. | 说明自己会的本领 |
| 询问能力句型 | Can you + 动词原形? | 询问对方会不会做某事 |
| 肯否回答 | Yes, I can. / No, I can't. | 回答 Can you...? 问句 |
| can 的用法规则 | can 后面永远跟动词原形 | I can sing. 不能说 I can sings |

## 三、解题方法
1. **TPR 动作记忆法**：说 sing 做唱歌状、说 jump 真跳一下，动作带动记忆
2. **才艺展示法**：用 I can... 向同学介绍自己的本领，学以致用
3. **句型替换操练**：固定 I can...，替换不同动词反复练
4. **听音选图技巧**：听清动词关键词（swim/draw），选对应动作图片
5. **问答接龙法**：同桌互问 Can you...? 并真实回答 Yes/No

## 六、常见考点
1. 听音选动作：听到 dance 选出跳舞图片
2. 单词英汉配对：swim—游泳、draw—画画
3. 句型问答配对：Can you jump? ↔ Yes, I can.
4. 看图选句：男孩跑步图片选 I can run.
5. 判断对错：I can sings.（×）应改为 I can sing.
6. 字母书写：规范书写字母 Ss Tt Uu
