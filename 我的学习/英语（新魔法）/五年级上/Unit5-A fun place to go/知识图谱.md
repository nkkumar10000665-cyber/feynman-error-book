## 一、核心概念

1. **娱乐场所词汇**：park 公园、zoo 动物园、cinema 电影院、museum 博物馆、playground 游乐场、beach 海滩
2. **活动词汇**：ride a bike 骑车、fly a kite 放风筝、see a film 看电影、have a picnic 野餐、take photos 拍照
3. **提建议句型**：Why don't we go to the zoo? / How about visiting the museum? / Shall we have a picnic?
4. **回应建议**：Good idea! / That's great! / Sorry, I can't.（同意与委婉拒绝）
5. **be going to 表将来**：We are going to the beach this Sunday.（计划好的安排）
6. **交际功能**：能邀请别人、提出建议，并谈论周末或假期计划

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 提建议三种句型 | Why don't we + 动词原形？/ How about + 动词-ing？/ Shall we + 动词原形？ | 邀请或提议做某事 |
| be going to 结构 | 主语 + be (am/is/are) + going to + 动词原形（He is going to swim.） | 表达计划、打算做某事 |
| be going to 疑问句 | Be + 主语 + going to + 动词原形？（Are you going to the park?） | 询问对方的计划 |
| How about 后接 -ing | How about flying a kite?（about 是介词，后接动词-ing） | 提建议句型之一 |
| 将来时间状语 | this weekend / tomorrow / next Sunday 与 be going to 连用 | 表明将来的时间 |

## 三、解题方法

1. **时态标志词定位法**：看到 tomorrow/next week，判断用 be going to 表将来。
2. **句型搭配检查法**：How about 后必接 -ing；Why don't we / Shall we 后接原形，做题时先找"标志词"。
3. **情景交际"问—答"配对法**：建议句型要配 Good idea!/Let's go! 等回应，背熟常用应答。
4. **听力预测法**：听前看选项中的地点与活动图，预测对话主题（去哪儿？做什么？）。
5. **写作"总—分—总"三段式**：总起计划（I'm going to…）→ 分述活动 → 表达期待（It will be fun!）。
