## 一、核心概念

1. **烹饪动词词汇**：cut 切、wash 洗、add 加、mix 搅拌、put 放、cook 煮、fry 煎
2. **厨具与材料词汇**：pan 平底锅、bowl 碗、knife 刀、oil 油、egg 鸡蛋、flour 面粉
3. **顺序连接词**：First 首先、Then 然后、Next 接着、Finally 最后
4. **祈使句**：Cut the potatoes. / Add some salt.（动词原形开头，省略主语 you）
5. **步骤描述句型**：First, wash the rice. Then, put it in the pot.（连接词 + 祈使句）
6. **交际功能**：能有条理地用英语说出做一道菜/一件事的步骤

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| 祈使句肯定式 | 动词原形 + 其他（Cut the bread.） | 发出指令、说明步骤 |
| 祈使句否定式 | Don't + 动词原形（Don't add too much salt.） | 提醒不要做某事 |
| 顺序连接词 | First → Then → Next → Finally，句首使用，后加逗号 | 叙述事情先后顺序 |
| 量词搭配 | some + 不可数材料（some oil/salt）；a/an + 可数（an egg） | 烹饪材料表达 |
| some 与 too much 辨析 | 适量用 some，过量用 too much（接不可数） | 提醒用量时使用 |

## 三、解题方法

1. **顺序连接词定位法**：看到 First/Then/Next/Finally，判断文章为"步骤说明文"，按顺序梳理内容。
2. **祈使句口诀法**："动词打头，省略主语"，判断句子是否为祈使句，改错题专用。
3. **流程复述法**：读完步骤后合上书，用四个连接词把流程复述一遍，检查理解。
4. **阅读找关键词定位法**：题目问某一步做什么，回原文找对应连接词后的句子。
5. **写作"步骤四段式"**：First→Then→Next→Finally 各写一句，就是一篇完整小短文。
