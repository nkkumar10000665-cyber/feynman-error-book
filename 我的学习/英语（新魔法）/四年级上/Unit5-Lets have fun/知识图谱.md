## 一、核心概念

1. **娱乐活动词汇**：watch a film 看电影、go swimming 去游泳、play games 玩游戏、ride a bike 骑车、fly a kite 放风筝、have a picnic 野餐
2. **游乐场所词汇**：park 公园、cinema 电影院、playground 游乐场、swimming pool 游泳池
3. **邀请用语**：Would you like to go with me? / Let's go to the park! / How about playing games?
4. **重点句型1（邀请）**：Would you like to…? 你愿意……吗？
5. **重点句型2（应答）**：Sure, I'd love to. / Sorry, I can't. I have to… 当然，我很乐意。/ 抱歉，我得……
6. **交际功能**：发出邀请、接受或礼貌拒绝邀请并说明理由

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
|------|-----------|----------|
| Would you like to…? | Would you like to + 动词原形？肯定答：Sure, I'd love to. | 礼貌发出邀请 |
| 委婉拒绝句型 | Sorry, I can't. I have to + 动词原形. | 拒绝邀请并说明理由 |
| Let's + 动词原形 | Let's go swimming! 答：Good idea! / OK! | 提议一起做某事 |
| go + doing 结构 | go swimming/shopping/fishing（运动娱乐类用ing） | 表达"去做某项活动" |
| How/What about…? | How about + 名词/doing？答：Great! / That's nice. | 提出建议 |

## 三、解题方法

1. **情景交际应答匹配法**：先看上句是邀请、建议还是请求，再从选项中找对应的功能性答语。
2. **邀请三步应答法**：接受=感谢+同意（Sure, I'd love to.）；拒绝=道歉+理由（Sorry…because/have to…）。
3. **to后还原法**：Would you like to后面跟动词原形，看到选项中有doing直接排除。
4. **go+doing词块法**：go swimming、go shopping、go fishing 作为固定词块记忆，不加to。
5. **语气判断法**：题目语境是朋友间邀约，选轻松口语化答语；正式场合选礼貌答语。
