## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
|------|-----------|----------|
| be going to表将来 | 主语 + be(am/is/are) + going to + 动词原形 | 表示计划、打算做某事 |
| be going to疑问句 | What/How/When + be + 主语 + going to + 动词原形？ | 询问将来的计划细节 |
| be动词随主语变 | I用am，he/she/it用is，you/we/they用are | 所有be going to句型 |
| 交通方式表达 | by + 交通工具（不加the）；on foot步行除外 | 回答How提问的方式 |

## 三、解题方法

1. **时态标志词定位法**：看到tomorrow/next week/this weekend，用be going to。
2. **be动词三查法**：写be going to句子前，先看主语定am/is/are，避免"I is going"类错误。
3. **计划描述四要素法**：按"去哪里（Where）—怎么去（How）—做什么（What）—何时去（When）"复述旅行计划。
4. **词块记忆法**：by MTR / take photos / watch the show 整块背诵。
5. **疑问词辨析法**：What问活动、How问方式、When问时间、Where问地点，看清疑问词再作答。

## 六、常见考点

1. be going to句型填空（注意am/is/are选择）
2. 句型转换：陈述句↔一般疑问句（Are you going to…?）
3. 对划线部分提问（What/How/Where）
4. 交通方式选择题（by bus / on foot）
5. 情景对话：谈论周末或假期旅行计划
6. 阅读理解：提取旅行计划中的地点、交通、活动信息
