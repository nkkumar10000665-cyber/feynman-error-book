## 一、核心概念

1. **交通工具词汇**：bus（公共汽车）、car（小汽车）、taxi（出租车）、MTR（地铁）、ferry（渡轮）、tram（电车）、minibus（小巴）
2. **by+交通工具**：by bus（乘公交）、by taxi（乘出租车）
3. **Let's 建议句型**：Let's go by bus.（我们乘公交去吧。）
4. **回应建议**：OK! / Good idea! / Let's go!
5. **交际功能**：提议出行方式并作出回应
6. **拓展表达**：How do we go there?（我们怎么去那里？）（初步感知）

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| Let's 句型 | Let's + 动词原形 | 提出建议"让我们……" |
| by 的用法 | by + 交通工具（无冠词，用单数） | by bus / by MTR，不能说 by a bus |
| go 短语 | Let's go + 地点 / Let's go by + 交通 | 去某地或乘某种交通工具 |
| 回应句 | OK! / Good idea! | 接受别人的建议 |

## 三、解题方法

1. **图片联想记单词**：把香港街景图和交通工具配对记忆（渡轮-海、电车-轨道）
2. **句型替换操练**：固定 "Let's go by ___."，替换不同交通工具
3. **情景对话角色扮演**：模拟一家人商量去公园的交通方式
4. **分类记忆法**：把交通工具按"陆上/海上/地下"分三类记忆
5. **听音选图**：听 "by ferry"，从多张图片中选出渡轮

## 六、常见考点

1. 看图选词：图片是渡轮，选 ferry
2. 句型填空：Let's ___ (go) to the park.（动词原形）
3. by 的用法判断：by bus ✔ / by a bus ✘
4. 应答选择：Let's go by tram. — ___（OK!）
5. 听力排序：按听到的交通工具顺序给图片编号
