## 一、核心概念

1. **房间词汇**：living room（客厅）、bedroom（卧室）、kitchen（厨房）、bathroom（浴室/洗手间）、dining room（饭厅）
2. **家具词汇**：sofa（沙发）、TV（电视）、bed（床）、table（桌子）、fridge（冰箱）
3. **There be 句型**：There is a sofa. / There are two beds.（有……）
4. **is/are 的选择**：单数用 There is，复数用 There are
5. **交际功能**：介绍自己家里的房间和物品
6. **拓展词汇**：new（新的）、big（大的）、nice（漂亮的）

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| There is | There is + a/an + 单数名词 | 表示"有一个……" |
| There are | There are + 数字/复数名词 | 表示"有多个……" |
| a/an 选择 | 元音音素前用 an，其余用 a | an egg, a bed |
| 提问句 | What's in the...? | 询问某处有什么东西 |

## 三、解题方法

1. **图片联想记单词**：画/看一套房子剖面图，把房间和家具标签贴上
2. **句型替换操练**：固定 "There is/are ___ in the ___."，替换家具和房间
3. **数数量判断**：看到两个以上物品就用 There are，一个用 There is
4. **情景对话角色扮演**：邀请同学"参观新家"，用英语介绍
5. **听音圈词**：听到 bedroom 就圈出卧室图片

## 六、常见考点

1. is/are 填空：There ___ two beds.（are）
2. 看图选词：图片是厨房，选 kitchen
3. 问答配对：What's in the living room? — There is a sofa.
4. 找错：There is two chairs.（is→are）
5. a/an 选择：___ egg（an）/ ___ sofa（a）
