## 一、核心概念

1. **食物词汇**：sandwich（三明治）、cake（蛋糕）、biscuit（饼干）、chicken（鸡肉）、egg（鸡蛋）
2. **饮料词汇**：water（水）、juice（果汁）、milk（牛奶）、Coke（可乐）
3. **礼貌点餐句型**：Would you like some juice?（你想要点果汁吗？）
4. **请求句型**：Can I have some water, please?（请给我一些水好吗？）
5. **应答句**：Yes, please. / No, thank you. / Here you are. / Thank you.
6. **交际功能**：野餐时礼貌地提供食物和提出请求

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| Would you like...? | Would you like + some + 食物/饮料？ | 礼貌询问对方要不要 |
| 应答 | Yes, please. / No, thank you. | 接受或婉拒都要礼貌 |
| Can I have...? | Can I have + some + 名词, please? | 礼貌地请求要某物 |
| some 的用法 | some + 可数复数/不可数名词 | some biscuits / some milk |

## 三、解题方法

1. **图片联想记单词**：把野餐篮子图片和食物饮料配对记忆
2. **野餐情景扮演**：铺野餐垫模拟真实分享食物，练完整对话
3. **句型替换操练**：固定 "Would you like some ___?" 替换食物
4. **礼貌用语对比**：对比中文"要不要"和英文 Would you like 的语气
5. **听音排序**：听对话，按提供食物的顺序给图片编号

## 六、常见考点

1. 应答配对：Would you like some cake? — ___（Yes, please.）
2. 看图选词：图片是果汁，选 juice
3. 句型填空：Can I ___ some water?（have）
4. 礼貌用语判断：拒绝时要说 No, thank you.（不是只"No!"）
5. 听力选择：听到 milk，从饮料图片中选牛奶
