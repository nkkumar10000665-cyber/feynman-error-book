## 一、核心概念

1. **宠物词汇**：dog（狗）、cat（猫）、rabbit（兔子）、bird（鸟）、fish（鱼）、hamster（仓鼠）、tortoise（乌龟）
2. **动作能力词汇**：run（跑）、swim（游泳）、fly（飞）、jump（跳）、climb（爬）
3. **can 能力句型**：It can run fast.（它能跑得很快。）
4. **can 否定句**：It cannot (can't) fly.（它不会飞。）
5. **can 疑问句**：Can it swim? — Yes, it can. / No, it can't.
6. **交际功能**：介绍宠物的本领，表达对宠物的喜爱

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
| --- | --- | --- |
| can 表能力 | 主语 + can + 动词原形 | 表示"会做/能做某事" |
| can 否定式 | 主语 + can't/cannot + 动词原形 | 表示"不会做某事" |
| can 疑问句 | Can + 主语 + 动词原形？ | 询问是否具备某能力 |
| 回答 | Yes, ... can. / No, ... can't. | 肯定/否定回答 |

## 三、解题方法

1. **图片联想记单词**：宠物图片+动作标签配对（fish-swim，bird-fly）
2. **TPR 全身反应法**：模仿动物动作并说 "It can jump!"，用身体记忆
3. **句型替换操练**：固定 "A ___ can ___."，替换宠物和动作
4. **能力表格法**：画表格给每种宠物打勾（can swim ✔ / can fly ✘），再口头造句
5. **情景对话角色扮演**：开"宠物才艺秀"，介绍自己宠物的本领

## 六、常见考点

1. 宠物与能力配对：fish — swim；bird — fly；rabbit — jump
2. can 后动词形式：It can ___ fast.（run，用原形）
3. 问答配对：Can it fly? — No, it can't.
4. 看图选词：仓鼠图片 → hamster
5. 判断正误：It can swims.（swims→swim，can 后用原形）
