## 一、核心概念

1. **美食节词汇**：food fair 美食节、stall 摊位、snack 小吃、drink 饮料、juice 果汁、salad 沙拉
2. **数量相关词汇**：a bottle of 一瓶、a box of 一盒、a plate of 一盘、enough 足够的
3. **购买用语**：How much is it? 多少钱？/ It's ten yuan. / Can I help you? 需要点什么？
4. **重点句型1（some/any）**：There are some sandwiches. / Are there any sandwiches? / There aren't any.
5. **重点句型2（much/many）**：How much juice do we need? / How many eggs do we have?
6. **交际功能**：在美食节上询问数量、购买食物、谈论食物储备

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
|------|-----------|----------|
| some用于肯定句 | some + 可数复数/不可数（some cakes / some milk） | 肯定句中表示"一些" |
| any用于否定疑问句 | any + 可数复数/不可数（There isn't any juice. / Do you have any eggs?） | 否定句和一般疑问句 |
| How many提问 | How many + 可数复数？（How many apples?） | 问可数事物的数量 |
| How much提问 | How much + 不可数名词？（How much water?）；也可问价钱 | 问不可数事物的量或价格 |
| much/many作限定词 | much + 不可数；many + 可数复数 | 肯定/否定句中表"许多" |

## 三、解题方法

1. **some/any句式判断法**：先看句子是肯定（用some）还是否定/疑问（用any）；注意"Would you like some…?"表邀请仍用some。
2. **可数性优先判断法**：做much/many题先圈出名词，判断可数→many，不可数→much。
3. **How much/many辨析法**：问价钱必用How much；问数量看名词可数性。
4. **量词词块记忆法**：a bottle of juice、a box of eggs、a plate of dumplings 整块记。
5. **购物对话模板法**：Can I help you?→I want…→How much is it?→It's…yuan.→Here you are.→Thank you.
