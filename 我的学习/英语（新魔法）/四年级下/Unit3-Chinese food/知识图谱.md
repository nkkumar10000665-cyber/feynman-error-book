## 一、核心概念

1. **中餐词汇（主食点心）**：rice 米饭、noodles 面条、dumplings 饺子、fried rice 炒饭、soup 汤
2. **中餐词汇（菜肴）**：sweet and sour pork 糖醋里脊、kung pao chicken 宫保鸡丁、mapo tofu 麻婆豆腐、spring rolls 春卷
3. **餐具与味道词汇**：chopsticks 筷子、bowl 碗、delicious 美味的、spicy 辣的、sweet 甜的、sour 酸的
4. **重点句型1（点餐）**：What would you like? / I'd like some noodles, please. 您要点什么？/ 请来些面条。
5. **重点句型2**：Would you like some rice? —Yes, please. / No, thank you. 要点米饭吗？
6. **交际功能**：餐厅点餐、询问与表达饮食喜好

## 二、公式与定理

| 名称 | 规则/句型 | 适用条件 |
|------|-----------|----------|
| 可数名词 | 有单复数之分，复数加s/es（dumpling→dumplings, bowl→bowls）；可用a/an/数词修饰 | 可以逐个计数的事物 |
| 不可数名词 | 无复数形式，不能加s，前面不用a/an（rice, soup, bread, water） | 无法逐个计数的物质/液体 |
| 点餐句型 | I'd like + 食物名词（=I would like） | 表达想要的食物 |
| some的用法 | some + 可数复数/不可数名词（some dumplings / some rice） | 肯定句中表示"一些" |
| 礼貌应答 | Yes, please. / No, thank you. | 回应Would you like…?食物类提问 |

## 三、解题方法

1. **可数不可数分类法**：把食物词汇分两类列表记忆——能数清的（egg/apple/dumpling）与数不清的（rice/soup/milk）。
2. **冠词判断法**：空格前有a/an，后面名词必须可数单数；有some则两类皆可。
3. **点餐情景三步法**：招呼（What would you like?）→点餐（I'd like…）→确认（Anything else?）。
4. **词块记忆法**：sweet and sour pork、a bowl of rice、a pair of chopsticks 整块记。
5. **文化联想法**：把中餐菜名与实物图片联想记忆，顺带了解中国饮食文化。
