# 费曼错题本Pro — 通用框架

## 这是什么

一个基于 AI 的智能错题本系统框架。从小学到大学都能用，历史错题永久保留，经验值持续累积。

核心功能：拍照录错题 → AI 五层追根溯源（含跨年级追因）→ 联网核验讲解 → boss 战变形题 → 艾宾浩斯复习 → 游戏化升级。

## 快速开始（3 步）

### 第 1 步：打开 Trae Work
浏览器打开 work.trae.cn，或下载桌面客户端。手机号登录。

### 第 2 步：设置工作目录
把"费曼错题本Pro"文件夹放在 D 盘（不要放桌面）。打开 Trae Work，左上角点"打开文件夹"，选中这个文件夹。AI 就能读写里面的所有文件了。

### 第 3 步：发送搭建指令
打开 AI设定.md，复制"第一步：搭建系统"里的指令，改掉方括号里的年级信息，发送。

AI 会自动上网搜索人教版教材目录，创建知识图谱和文件夹结构。

## 搭建完成后

1. 按 AI设定.md 的"第二步"设置记忆
2. 按 AI设定.md 的"第三步"添加 12 条规则
3. 开始用：截图（Win+Shift+S）或拍照发题，AI 自动处理

## 每天怎么用

**打开 控制台.html，这一页就够了。**

- 顶部状态栏：XP/等级/超期复习/待打boss战（AI 自动更新）
- 待办清单：现在最该做的事，按紧急程度排序
- 功能导航：10 个功能全在这，点「复制」把指令粘贴给 AI，不用记任何指令
- 定时提醒：每天晚上自动推送每日战报（昨日错题回顾+XP变化+今日复习任务）

## 以后每次使用

打开 Trae Work → 打开同一个文件夹 → 打个招呼（AI 自动播报状态+行动菜单）或直接拍照发题。不用重新设置。
记忆和规则保存在 Trae Work 里，知识图谱和错题存在文件夹里。

## 12 条规则速览

| 规则 | 名称 | 作用 |
|------|------|------|
| 1 | 拍照自动处理 | 拍照→识别→归档→五层分析→讲解→出boss战 |
| 2 | 蒙题检测 | 标记"我蒙的"→出验证题→检测真假 |
| 3 | boss战判题 | 批改变形题→讲解→记XP→升级→解锁成就 |
| 4 | 艾宾浩斯复习 | 6轮科学复习→超期提醒→连续3次答对标记掌握 |
| 5 | 联网核验 | 公式/定理/概念上网核验，标注来源 |
| 6 | 跨学科分析 | 同一底层能力跨学科出错时关联分析 |
| 7 | 习惯性错误 | 同类错因3次以上自动触发模式分析 |
| 8 | 历史检索 | 6种方式快速检索历史错题 |
| 9 | 语言风格 | 口语化+游戏语言+不给答案提示 |
| 10 | 标准会话流程 | 四阶段：录入→讲解→boss战→会话收尾总结 |
| 11 | 知识图谱互联 | 图谱查看+知识链条追踪+跨章节导航+知识全景图 |
| 12 | 智能功能菜单 | 开场播报状态+行动菜单，不用记指令 |

## 日常使用

打开 控制台.html 看状态和功能指令 → 拍照发题 → 做 boss 战 → "结束"收总结。

或直接打个招呼，AI 播报状态并列出行动菜单，选编号即可。

详见 使用说明.html。

## 验证系统

在 PowerShell 中运行：

```powershell
.\verify_system.ps1
```

检查核心文件、全局文件、模板文件、AI规则数量、章节完整性。
